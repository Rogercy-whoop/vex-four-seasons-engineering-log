# How VEX led to my other projects

Each of these began with a question VEX left me. The full stories are in their own repositories.

| Project | The VEX connection | Link |
|---|---|---|
| **VEX Auton Visualizer** (Aug–Oct 2026) | After two seasons of tuning autonomous routines by trial and error, I read our template and found that every 2025–26 drive move had ended on its timeout. I built a simulator that runs a team's real code on a laptop; all four teams in our club now use it. | [vex-auton-visualizer](https://github.com/Rogercy-whoop/vex-auton-visualizer) |
| **HIKROBOT internship** | I watched automated guided vehicles drift off their planned paths on worn concrete: the same drift I had blamed on my own code all season in VEX. | [JetRover README, "Why this exists"](https://github.com/Rogercy-whoop/jetrover-control-experiments#why-this-exists) |
| **JetRover control experiments** (self-funded) | I studied that drift properly on a robot I bought myself: PID on an ESP32 first, then a heading controller that keeps a robot straight when one side slips. | [jetrover-control-experiments](https://github.com/Rogercy-whoop/jetrover-control-experiments) |
| **TRI wall-climbing robots** | On the wall-climbing robots I tested at TRI, I met the same lesson as in my JetRover motor tests: a maximum rating is something a machine can *reach*, not something it can be held at. | [JetRover README, Stage 4b](https://github.com/Rogercy-whoop/jetrover-control-experiments#stage-4b-main-experiment-can-the-base-reach-the-acceleration-i-calculated) |
